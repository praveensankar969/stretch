Stretch is free and open source. Choose the build that matches your Mac from the published GitHub release.

Get Stretch for Mac

Apple Silicon: choose the file ending in -arm64.dmg for an M-series Mac.
Intel: choose the file ending in -x64.dmg.

View published Mac builds ↗

This website previews the 2.0 redesign. Version 2.0 downloads will appear once the release is published. Check the version on GitHub before downloading.

Make yourself at home

Open the DMG, drag Stretch into Applications, and launch it. Stretch lives in your menu bar. Choose your reminder interval and quiet hours; you can change both later.

For a build that hasn’t been notarized, macOS may ask you to approve it in System Settings → Privacy & Security. Only open a build you trust. Release notes should state its signing and notarization status.
